# DINO / SEVENTEEN Client Page

Deploy the contents of this package at the root of `client.plusalpha.agency`.

Expected URL:
`https://client.plusalpha.agency/dino-svt/2026/`

Folder structure:

dino-svt/
└── 2026/
    ├── index.html
    └── assets/
        ├── pa-logo.svg
        ├── dino-profile.png
        └── picheolin.jpg

Important:
- Keep `index.html` and the `assets` folder together.
- Image paths are relative, so they will not depend on `/mnt/data` or any local machine path.
- YouTube thumbnails remain remote assets loaded from YouTube.
